장기훈수 (Janggi Hunsu) 개인정보처리방침

개발자: 장기훈수
시행일: 2026년 11월 26일

장기훈수(Janggi Hunsu, 패키지명 janggi.hunsu)는 끝난 장기 대국을 기기 안에서 복기하는 앱입니다. 개발자는 이 앱으로 사용자의 개인정보를 수집하거나, 서버로 전송하거나, 제3자에게 판매·제공하지 않습니다.

1. 화면 녹화

  • 사용자가 [기보 가져오기]를 시작하고 Android 화면 공유를 허용한 경우에만, 최대 5분 동안 녹화합니다. 소리는 녹음하지 않습니다.
  • 녹화에는 공유한 화면에 보이는 알림, 닉네임, 프로필 등이 포함될 수 있습니다. 앱은 그중 장기판, 기물의 위치, 수 넘김 표시, 대국 결과만 분석에 사용합니다.
  • 녹화 파일은 앱 내부 임시 공간에 저장되고, 분석이 끝나면 성공 여부와 관계없이 삭제됩니다. 앱이 강제로 종료되어 파일이 남은 경우에는 다음 녹화 때, 또는 사용자가 앱의 캐시를 지우거나 앱을 삭제할 때 지워집니다.

2. 기기에 저장하는 정보

  • 기보(수순, 날짜, 사용자가 붙인 제목, 대국 결과)와 분석 결과
  • 앱 설정과 사용자가 직접 선택한 분석용 신경망 파일

이 정보는 앱 내부 저장 공간에만 보관되며 구글 자동 백업에 포함되지 않습니다. 사용자가 기기 제조사의 기기 간 이전 기능을 쓰면 새 기기로 옮겨질 수 있습니다.

3. 권한

  • 화면 공유(포그라운드 서비스, 미디어 프로젝션): 기보 재생 화면 녹화
  • 알림: 녹화와 분석 상태 안내. 거부해도 기보를 가져올 수 있습니다.

인터넷, 접근성, 연락처, 위치, 마이크, 카메라 권한은 사용하지 않습니다.

4. 기기의 다른 앱과 외부 링크

  • ‘장군’, ‘멍군’ 등의 짧은 안내 낱말은 기기에 설치된 음성 합성 엔진으로 읽습니다. 화면, 기보, 개인정보는 전달하지 않으며 설정에서 소리를 끌 수 있습니다.
  • 사용자가 외부 링크를 누르면 브라우저에서 열리며, 해당 사이트의 방침이 적용됩니다.
  • 기보 읽기에 문제가 있을 때 나오는 [문의 메일]이나, 앱이 꺼진 뒤 다음 실행 때 나오는 [메일 보내기]를 누르면 기기의 메일 앱이 열리고, 앱 버전·지원하는 장기 앱의 버전·기종·Android 버전·화면 크기와 (해당할 때) 기보 읽기 기록이나 오류 내용이 본문에 미리 적힙니다. 장기 앱의 버전은 그 앱이 설치되어 있는지와 버전만 확인하며, 다른 설치 앱 목록은 보지 않습니다. 사용자가 내용을 확인하고 직접 보낼 때만 개발자에게 전달되며, 앱이 스스로 보내는 일은 없습니다. 받은 메일은 문의에 답하고 앱을 고치는 데에만 씁니다.

5. 보유 기간과 삭제

  • 기보함에는 최근 50판과 즐겨찾기 한 판이 남습니다. 풀지 않은 오답 노트 문제가 있는 판은 기보함에서 빠진 뒤에도 최대 300판까지 기기에 남을 수 있습니다.
  • 기보함에서 판을 삭제할 수 있으며, 풀지 않은 문제가 있으면 문제를 풀거나 [그만 보기]를 할 때까지 남습니다.
  • 앱이 갑자기 꺼지면 오류 내용(시각과 프로그램 위치)만 기기 안에 저장했다가, 다음 실행 때 메일로 보낼지 묻고 지웁니다.
  • Android 설정에서 앱 데이터를 지우거나 앱을 삭제하면 모든 정보가 즉시 삭제됩니다. 개발자는 사본을 갖고 있지 않습니다.

6. 보안

정보는 Android가 다른 앱의 접근을 차단하는 앱 전용 공간에 저장되며, 앱에 인터넷 권한이 없어 개발자에게 전송되지 않습니다.

7. 어린이

앱은 어린이를 포함한 어떤 사용자의 개인정보도 수집하지 않습니다.
