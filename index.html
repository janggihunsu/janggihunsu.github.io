장기훈수 (Janggi Hunsu)

방금 둔 장기, 화면 녹화 한 번이면 스톡피쉬가 한 수씩 짚어 주는 복기 앱입니다. 로그인·광고·결제가 없고, 인터넷 권한 없이 폰 안에서만 분석합니다.

Janggi Hunsu is a free review app for Janggi (Korean chess). It reads a screen recording of a finished game and analyses every move on the phone with Fairy-Stockfish: no internet permission, no login, no ads. Released under GPL-3.0; the source code of each published version is posted above. Contact: 135aksfn@gmail.com
